A note on languages

This sandbox currently runs Python only. Real in-browser execution for C and Java needs a different, heavier kind of runtime (a WebAssembly-compiled compiler for C; a JVM-in-the-browser for Java) — both are much larger downloads and less mature than Python's. They may be added later; for now, use the Theory Reference and Debugger Arena pages for C and Java practice.
